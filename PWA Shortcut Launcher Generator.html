How To Put This Online For Free (3 Mins)

Google Drive shortcuts need to be hosted on an HTTPS website so Android allows them to be saved. You can host this 100% free with GitHub Pages or TinyHost without knowing any backend code!

A

Method 1: GitHub Pages (Recommended)

  1. Go to github.com/new and create a public repository (e.g. family-drive).
  2. Click "uploading an existing file" and drag in the 3 downloaded files: index.html, manifest.json, and sw.js.
  3. Go to repo Settings > Pages > Set Branch to "main" and click Save.
  4. GitHub gives you a link like https://yourusername.github.io/family-drive/. Text that link to your sister!
B

Method 2: Drop & Host (Even Easier, No Account)

Put the 3 files in a ZIP file and upload to tiiny.host or Netlify Drop. They give you a live HTTPS link instantly with zero coding.
